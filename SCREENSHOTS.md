## Sessions and tabs

Expand a saved session to resume one of its shell tabs or open a new one. Each session and tab has its own options menu.

![Desktop connection choices with saved sessions and a direct-shell action](assets/screenshots/desktop-sessions.jpg)

<img src="assets/screenshots/phone-sessions.jpg" alt="Phone session picker with existing shell tabs" width="320">

## Session lifetime

Independent sessions keep running when Shellport stops or restarts; managed sessions end with it. Both keep running when you disconnect. Settings chooses the default for new sessions. When both modes are enabled, Advanced lets you choose a different lifetime for a new session.

<p><img src="assets/screenshots/phone-settings.jpg" alt="Settings with the default session lifetime and counts for both modes" width="320"> <img src="assets/screenshots/phone-lifetime.jpg" alt="Advanced connection options with the compact Managed and Independent choices" width="320"></p>
